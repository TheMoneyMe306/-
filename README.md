# ครัวแม่ปุ้ง — เว็บสั่งอาหาร

เว็บสั่งอาหารสไตล์เดียวกับ 306 Smoky Bite แต่ปรับธีมสี/เนื้อหาให้เป็นเมนูข้าวราดของครัวแม่ปุ้ง

## ไฟล์ในชุดนี้
- `index.html` / `styles.css` / `main.js` — ตัวเว็บไซต์
- `logo.png` — โลโก้ร้าน (พื้นหลังโปร่งใส) ใช้เป็นทั้งโลโก้บน header และ favicon แล้ว
- `AppsScript_Code.gs` — โค้ด backend สำหรับ Google Sheets + แจ้งเตือน LINE (deploy แยกจากของร้านเดิม)
- รูปเมนู 9 ไฟล์ (จากรูปที่ลูกค้าส่งมา ใช้ชื่อไฟล์ภาษาอังกฤษให้ตรงกับ id เมนูใน main.js)

## ก่อนเปิดใช้งานจริง ต้องแก้ไขตรงนี้ก่อน
1. **เบอร์โทร/ที่อยู่ร้าน** — ในไฟล์ `index.html` ช่วง `.footer` มีข้อความ `[ใส่ที่อยู่จัดส่งของร้าน]` และ `[ใส่เบอร์โทรร้าน]` ให้แก้เป็นของจริง
2. **ลิงก์ LINE OA** — ในไฟล์ `main.js` ตัวแปร `LINE_OA_LINK = "#"` ให้เปลี่ยนเป็นลิงก์ LINE OA ของครัวแม่ปุ้ง และแก้ `href="#"` ของปุ่ม `.line-fab` ใน `index.html` ด้วย
3. **Apps Script Web App URL** — ในไฟล์ `main.js` ตัวแปร `APPS_SCRIPT_URL` ยังเป็นข้อความ placeholder ต้อง deploy `AppsScript_Code.gs` เป็นของครัวแม่ปุ้งเอง (ห้ามใช้ URL ของ 306 Smoky Bite ซ้ำ เพราะออเดอร์จะไปลง Sheet ผิดร้าน) แล้วนำ URL มาใส่แทน
4. **Channel Access Token ของ LINE** — ในไฟล์ `AppsScript_Code.gs` ต้องใส่โทเคนของ LINE OA ครัวแม่ปุ้งเอง (คนละอันกับ Smoky Bite)
5. **รูปเมนู 1 รายการที่ยังไม่มีรูปจริง** (ใช้รูปชั่วคราวไปก่อน):
   - "ข้าวกุ้ง+หมึกผัดผงกะหรี่" — ใช้รูปข้าวกุ้งผัดผงกะหรี่ไปพลางก่อน (ยังไม่มีรูปที่เห็นหมึกชัดเจน)

## เมนูล่าสุด (13 รายการ)
เพิ่ม "สะโพกไก่นึ่งสมุนไพร ชิ้นละ 40 บาท" เป็นเมนูที่ 11 และอัปเดตเมนู "ไก่นึ่งสมุนไพร เป็นกับข้าว" (เมนูที่ 6) ให้ระบุจำนวนชิ้นชัดเจนแล้ว (ปีกไก่ 2 + น่องไก่ 1 ชิ้น รวม 3 ชิ้น 50 บาท) พร้อมเปลี่ยนเป็นรูปจริงจากโปสเตอร์ล่าสุด — ทั้งสองเมนูนี้เป็นเมนู "กับข้าว" ขายแยกไม่รวมข้าว (ตั้งค่า `side: true` ในไฟล์ `main.js`)

## เมนูใหม่ที่เพิ่มล่าสุด (ก.ย. 2569)
- "ข้าวหมึกกระเทียม" 50 บาท (รูป `muk-krathiam.jpg`)
- "ข้าวหมึกผัดผงกะหรี่" 50 บาท (รูป `muk-phad-phong-kari.jpg`)
ทั้งสองเมนูอยู่ในหมวด "เมนูข้าวหน้ากุ้ง / หมึก" (ตัวแปร `shrimpMenus` ในไฟล์ `main.js`)

## วิธีใช้งาน
เปิด `index.html` ในเบราว์เซอร์ได้ทันที (ทุกไฟล์ต้องอยู่โฟลเดอร์เดียวกัน) หรืออัปโหลดทั้งโฟลเดอร์ขึ้น GitHub Pages / โฮสต์อื่น ๆ ได้เหมือนเว็บ Smoky Bite เดิม
